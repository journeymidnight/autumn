TaskStatus: completed
Task scope: PS write performance optimization (F048, F049)

Current summary:
  Write throughput: 6.3K → 32.9K ops/s (5.2x improvement)

  Optimizations applied:
  1. partition_thread_main: spawn concurrent tasks (batch_size 1→60-80)
     - Root cause: sequential request processing defeated group commit
     - Effect: 6.3K → 25K ops/s (4x)
  2. TCP/read buffer 512KB (SO_SNDBUF/SO_RCVBUF + read buf)
     - Root cause: 128KB TCP buf + 64KB read buf for 280KB batch payloads
     - Effect: best-case fanout 1.1→0.86ms, extent_bench +20%
  3. F048: Zero-copy frame write (vectored write in ConnPool)
     - Root cause: 280KB memcpy per append in Frame::encode()
     - Effect: p99 93→34ms
  4. F049: spawn_blocking for SSTable build in flush
     - Root cause: CPU-intensive build_sst_bytes blocked compio event loop
     - Effect: 25.8K → 32.9K ops/s, bad seconds 4-15K → 21-35K

  Stream layer baseline (confirmed, no degradation):
  - extent_bench depth=64: 482 MB/s (4KB append)
  - append_benchmark 1-replica batch=16: 197K ops/s

Main gaps:
  - Still ~2x from 80K target. Remaining bottleneck: 3-replica fanout
    avg ~1.5ms (good seconds 0.9ms, bad seconds 2.3ms).
  - Compaction CPU work still on partition thread (lower priority than flush)
  - PS main thread handles 256 connections on single compio thread
