  Branch: perf-r1-partition-scale-out (worktree /data/dongmao_dev/autumn-perf-r1)

  Collapsed the P-log write hot path from two compio tasks to one:

    Before:
      ps-conn → PartitionRouter mpsc → P-log task 1 (partition_thread_main)
                                          │
                                          └ spawn_write_request → P-log task 2
                                               │ dispatch_partition_rpc
                                               │ handle_put
                                               │   (resp_tx, resp_rx) = oneshot
                                               │   write_tx.send(..) ── mpsc ──▶
                                               │   resp_rx.await              P-log task 3 (background_write_loop_r1)
                                               │                                  │
                                               │                                  │ SQ/CQ batch + Phase 3
                                               │                                  │   inner resp_tx.send(key)
                                               └ req.resp_tx.send(encode(PutResp))

    After (F099-D):
      ps-conn → PartitionRouter mpsc → P-log task (merged_partition_loop)
                                          │
                                          │ select(req_rx, inflight.next()):
                                          │   req (PUT/DELETE/STREAM_PUT) →
                                          │     decode inline, push to pending
                                          │     with WriteResponder{outer=req.resp_tx}
                                          │   req (GET/HEAD/RANGE/..) →
                                          │     dispatch_partition_rpc inline
                                          │   completion (SQ/CQ) →
                                          │     finish_write_batch →
                                          │     WriteResponder::send_ok →
                                          │     encode PutResp and forward to
                                          │     outer resp_tx directly

  Architectural payoff summary:
    The primary win is structural, not purely perf. The P-log write
    hot path is now one compio task + one mpsc send + one oneshot,
    against the old two tasks + two mpsc sends + two oneshots +
    Waker cascade. This is the foundation for any future "reduce
    sync-RTT coupling" work — a simpler task graph makes it easier
    to reason about whether a given Put spends its time in CPU vs
    RTT vs lock contention. The +8.5 % write headroom at the 256
    × d=1 ceiling is exactly what F099-A predicted; the remaining
    gap to the 70 k "A+B combined" estimate is attributable to the
    RTT-client-sync barrier documented in F099-C (256 sync clients
    × ~4 ms batch RTT ≈ 64 k theoretical, and we are now at 57.6 k
    median — close to that envelope).
