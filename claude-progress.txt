Current summary:
  Branch: perf-r1-partition-scale-out (worktree /data/dongmao_dev/autumn-perf-r1)

  Replaced the per-extent ExtentWorker 3-task pipeline (reader → worker →
  completion via mpsc+oneshot, commit 3261702) with an INLINE
  FuturesUnordered inside `handle_connection` — one compio task per TCP
  connection, no cross-task hand-offs, no per-extent worker pool.

  Rationale: the 3-task pipeline introduced two mpsc hand-offs per request
  cycle, each costing several µs of scheduler round-trip. At the 4-5µs/op
  baseline this TRIPLED per-op latency and regressed extent_bench write
  depth=64 from 210k → 68k ops/s (-68%). Since end-to-end
  perf_check.sh --shm was RTT-bound at 53k ops/s, the microbench
  regression was masked — but it would become a hard ceiling once R4 steps
  4.3/4.4 remove upstream serialisation.

  New design (single task, inline FU):
    crates/stream/src/extent_node.rs::handle_connection
      • FuturesUnordered<Pin<Box<dyn Future<Output=Vec<Bytes>>>>>
        holds pending batch I/O futures (inflight_cap via
        AUTUMN_EXTENT_INFLIGHT_CAP env, default 64).
      • Per loop iteration:
          1. reader.read(buf) — blocking await for the next TCP burst.
          2. now_or_never drain of any completions that landed during (1).
          3. feed decoder → process_frames_backpressured:
              - groups consecutive same-extent APPEND → 1 append future
              - groups consecutive same-extent READ  → 1 read future
              - each control RPC → 1 dispatch future
              - when inflight.len() >= cap mid-push, await one
                completion to free a slot (tx_bufs accumulates its bytes)
          4. drain ALL inflight futures → tx_bufs
          5. ONE write_vectored_all(tx_bufs) — preserves 1-syscall-per-
             burst coalescing.
      • On EOF: drain remaining inflight, flush, exit.

    crates/stream/src/extent_node.rs::build_append_future
      Standalone async fn. Runs ACL synchronously (eversion refresh via
      manager if needed; sealed / eversion / revision / commit checks;
      WAL batch write if must_sync+small; extent.len reservation) THEN
      returns a Pin<Box<dyn Future>> that awaits write_vectored_at
      (pwritev) + optional sync_all. Early ACL rejections return a
      pre-resolved future (no I/O).

    crates/stream/src/extent_node.rs::build_read_future
      Same shape for READ batches. Future body runs preads sequentially
      inside one scope — each pread is ~1µs, responses emitted as a
      single Vec<Bytes>.

    crates/stream/src/extent_node.rs::process_frames_backpressured
      Decodes frames from the decoder, groups by msg_type+extent_id,
      invokes the build_* helpers, and pushes the resulting futures onto
      `inflight`. Back-pressure macro drains completions into tx_bufs
      when inflight would exceed cap.
