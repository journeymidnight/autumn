Current summary:
  F012 (erasure coding) fully implemented in autumn-rs.

  New erasure.rs module (autumn-rs/crates/stream/src/erasure.rs):
  - ec_encode(payload, data_shards, parity_shards) -> Vec<Vec<u8>>
    Same formula as Go: per_shard = (size+data_shards+4-1)/data_shards, min 4
    Length trailer: big-endian u32 at last 4 bytes of last data shard
  - ec_decode(shards, data_shards, parity_shards) -> Vec<u8>
    Uses reconstruct_data() for missing shard recovery, reads length from trailer
  - ec_reconstruct_shard(shards, data_shards, parity_shards, missing_index) -> Vec<u8>
    For recovery: reconstructs exactly the shard bytes the failed node held
  - Crate: reed-solomon-erasure = "6" (pure Rust, SIMD)

  StreamClient write path (append_payload):
  - Checks parity.is_empty() to detect EC mode
  - If EC: ec_encode → per-node shard payloads; fan-out indexed by shard position
  - If replication: same payload to all nodes (unchanged)
  - All shards have equal byte length → offsets consistent across nodes

  StreamClient read path (read_bytes_from_extent):
  - If EC: parallel reads to all data+parity nodes, parity reads delayed 20ms
  - Wait for data_shards successes, then ec_decode → original payload
  - If replication: existing sequential fallback (unchanged)

  ExtentNode recovery (run_recovery_task):
  - If replication: existing full-copy path (unchanged)
  - If EC: copies individual shards from healthy peers (data_shards needed)
    Calls ec_reconstruct_shard to rebuild the missing shard
    Writes reconstructed shard to local extent file
